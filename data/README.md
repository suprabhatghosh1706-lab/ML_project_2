# Dataset setup

Download the public **Credit Card Fraud Detection** dataset commonly known as the ULB dataset from Kaggle.

Expected CSV filename:
`creditcard.csv`

Put it here:
`data/creditcard.csv`

Expected columns:
`Time`, `V1` ... `V28`, `Amount`, `Class`

`Class` must use `1` for fraud and `0` for legitimate transactions. Verify the downloaded dataset's description and licence before use. Do not put real cardholder data here.
